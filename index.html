Optional shortcut

Fast track — let the script do it

If you'd rather not type every command by hand, there's a setup script that handles the boring parts. It checks what you already have installed, clones your chosen repo, sets up the environment, and writes your config files.

It deliberately stops and asks you for the two things only you can do: your ElevenLabs API key, and the OAuth logins for your calendar and email. It never guesses at those.

macOS / Linux / Git Bash

terminal
$chmod +x setup-jarvis.sh ./setup-jarvis.sh

Windows — PowerShell

powershell
>powershell -ExecutionPolicy Bypass -File .\setup-jarvis.ps1

Prefer to understand every step? Skip this and work through Steps 1–7 below. The script just automates what those steps describe — doing it by hand is the better way to learn it.

Before you start

What you'll need before you dive in

Get these ready first. Skipping this step is the #1 reason setups break halfway through.

  • A laptop — Mac, Windows, or Linux all work.
  • Claude Code installed — the AI coding agent that handles the boring setup work for you. Download it from claude.com/claude-code.
  • A GitHub account — free. Sign up at github.com if you don't have one.
  • An ElevenLabs account — for the voice. The free tier is enough to start. Sign up at elevenlabs.io.
  • Node.js and Python installed — most repos need one or both. Claude Code will tell you if something is missing and can install it for you.
  • About 30–45 minutes of quiet time.

02

Open Claude Code and Hand It the Repo

Open Claude Code in your terminal. Paste the repo link and tell it what you want, in plain English.

prompt
›Clone this repo, install everything it needs, and get it running on my machine: https://github.com/OpenInterpreter/open-interpreter

Claude will now do the boring part for you:

  • Clone the repo into a folder on your computer.
  • Read the README to figure out what's required.
  • Install dependencies — Python packages, Node modules, whatever the repo needs.
  • Set up a virtual environment if the project uses one.
  • Run any initial setup scripts.

If it hits an error — missing tool, wrong version of Python, permission issue — it will tell you and usually fix it itself. You just watch.

Tip: Keep the terminal window open so you can see what it's doing. If it asks a question ("Install Homebrew?" "Overwrite this file?"), answer it.

Test That It Runs

Once Claude Code says setup is done, run the agent and confirm it actually answers you.

Ask Claude:

prompt
›Start the agent and let me talk to it.

You should see the assistant boot up in the terminal (or a small window, depending on the repo). Type a test message like "What's the time?" and confirm it responds.

If it doesn't respond, tell Claude:

prompt
›It's not responding. Here's the error: [paste the error]. Fix it.

Claude will debug and re-run. This is normal — expect one or two rounds of fixing on any real setup.

04

Add a Voice with ElevenLabs

This is the fun part. Right now your agent replies in text. Let's give it a voice.

4a · Get your ElevenLabs API key

  1. Log in to elevenlabs.io.
  2. Click your profile icon (top right) → Profile + API key.
  3. Copy the API key. Keep it somewhere safe — do not share it publicly.

4b · Pick a voice

  1. In ElevenLabs, go to VoiceLab or Voices.
  2. Browse the library — pre-made voices (British, deep, calm, energetic) or clone your own.
  3. Pick one you like. Copy its Voice ID (small icon next to the voice name).

4c · Tell Claude to wire it up

Back in Claude Code, say:

prompt
›Add ElevenLabs voice output to the agent. Here's my API key: [paste key]. Here's the voice ID I want: [paste voice ID]. Make sure every response the agent gives is also spoken out loud.

Claude will edit the code, add the ElevenLabs SDK, and route the agent's text responses through their text-to-speech API. Restart the agent and it should now speak.

Tip: If you want the voice to sound more like the movie Jarvis, search ElevenLabs for a calm British male voice. Or clone your own and rename it "Jarvis."

05

Connect Your Own Tools

This is where it stops being a toy and starts being useful. Connect the agent to the apps you already use.

Common connections worth setting up first:

  • Calendar — Google Calendar, Apple Calendar, Outlook — so it can tell you what's on your schedule.
  • Email — Gmail, Outlook — so it can triage your inbox and summarize what needs a reply.
  • Files — a specific folder on your computer — so it can read, search, and summarize documents.
  • Notion / Docs — so it can pull notes, meeting minutes, or project briefs.
  • Slack / Discord — so it can catch you up on unread threads.

For each one, tell Claude what you want. Example:

prompt
›Connect the agent to my Google Calendar. When I say "what's my day look like," I want it to read my events out loud.

Claude will:

  • Install the right library or MCP connector.
  • Walk you through the OAuth flow — you'll click a link, log in to Google, approve access.
  • Store the credentials safely on your machine.
  • Add a command to the agent so it knows what to do when you ask.

Tip: Repeat for each tool. Add them one at a time — don't try to connect everything at once. Test each one before moving on.

06

Build Your Own Commands

Now customize. Think about the 3–5 things you actually do every morning, and make the agent do them.

Examples people build:

"Good morning"Reads today's calendar, your top 3 unread important emails, and the weather.
"Inbox status"Tells you how many unread emails, which ones are from important senders, and which are still waiting for your reply.
"Standup mode"Summarizes what you did yesterday from your calendar and commits, then asks what you're doing today.
"Focus mode"Mutes Slack, blocks distracting websites for 90 minutes, and starts a timer.
"Wind down"Reads tomorrow's first meeting, dims your screen, and plays a calm playlist.

Tell Claude what you want in plain English. It writes the command, wires it into the agent, and tests it.

07

Make It Yours

Small tweaks that make the agent feel personal — identity, personality, boundaries, and a startup phrase.

Give it a nameIn the agent's system prompt, tell it "Your name is Jarvis" (or Friday, or whatever). Every response will use that identity.
Give it a personality"You are dry, slightly sarcastic, and never use exclamation marks." Or "You are warm, encouraging, and always suggest one small next step."
Set boundaries"Never send an email without asking me first." "Always confirm before deleting a file."
Add a startup phrase"When you boot up, say: 'Good morning. I've been waiting.'"
prompt
›Update the agent's system prompt: your name is Jarvis, you are dry and slightly sarcastic, you never use exclamation marks, and you always confirm before deleting a file or sending an email.

Tell Claude what you want. It edits the system prompt.

When things break

Troubleshooting — the common ones

Every one of these has a known fix. Click to expand.

Claude will install the missing runtime for you. Just say: "I'm missing [tool]. Please install it."

On Mac/Linux, some installs need sudo. Claude will tell you when to type your password. Never paste your password into Claude — type it directly in the terminal when prompted.

The free tier has a monthly character limit. Either upgrade, or switch to a local text-to-speech engine — Claude can wire up Piper or Coqui TTS instead. Both are free and run locally.

Check your system audio output. Also confirm the ElevenLabs API key is valid by pasting it into a test call — Claude can do this in one line.

Repos update. If something suddenly stops working, tell Claude: "The agent worked yesterday but now throws this error: [paste]. Pull the latest repo changes and fix it."

Level up

What to do next

You now have a working local AI assistant. To take it further:

01

Add more connectors

Every tool you connect makes the agent more useful. Start with your top 3 apps.

02

Run it as a background service

So it starts automatically when you boot your laptop. Ask Claude to set this up.

03

Give it a wake word

So you can say "Hey Jarvis" instead of typing. This needs a small extra library — Claude can wire it up.

04

Back up your config

Push your customized version to your own private GitHub repo. If your laptop dies, you can restore your Jarvis in 10 minutes.
